AI-Driven Smart Irrigation Prediction

Project Overview

This project focuses on developing a Machine Learning-based Smart Irrigation Prediction system to classify irrigation requirements into three categories: Low, Medium, and High.

The project uses agricultural and environmental features to identify irrigation requirements and evaluate the performance of different machine learning classification algorithms.

Objectives

- Analyse agricultural and environmental data.
- Predict irrigation requirements using Machine Learning.
- Compare the performance of multiple classification algorithms.
- Identify important features influencing irrigation requirements.
- Evaluate model performance using different evaluation metrics.

Machine Learning Algorithms

The following classification algorithms are implemented:

1. Decision Tree
2. Random Forest
3. Extra Trees
4. Gradient Boosting
5. Logistic Regression
6. Support Vector Machine (SVM)

- Python

Project Workflow

1. Data Loading
2. Data Cleaning and Preprocessing

4. Feature Selection
5. Model Training
6. Model Evaluation
7. Feature Importance Analysis
8. Comparative Model Analysis
9. Irrigation Prediction

Target Variable

The target variable is "Irrigation_Need", which contains three categories:

- Low
- Medium
- High

Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- Macro F1-score
- Weighted F1-score
- Balanced Accuracy
- Confusion Matrix
